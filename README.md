# YZA V2 — archived design preview

Live preview: https://drhatim-dev.github.io/yza-v2-preview/

This is the redesign preserved on 10 September 2026, before the production website was restored to its previous design. It includes the redesigned homepage, collections, product pages, studio, stockists, cart, checkout, newsletter and chat styling.

This repository is a static design preview. Forms, orders, payment requests and production analytics are disabled. Product data reflects the archived version. No customer records, credentials, payment secrets or PHP backend files are included. WordPress is not included.

The saved local V2 snapshot remains unchanged. GitHub Pages adaptations are limited to routing, asset paths and preview-only guards. The production site is not deployed from this repository.
